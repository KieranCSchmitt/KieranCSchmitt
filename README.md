# Kieran Schmitt

**AI interfaces · Systems software · Graphics & simulation**

I build software that makes complex tools easier to understand and use. I'm an economics student at UNC–Chapel Hill, with a background in journalism and civic projects.

### What I work on

- **AI interfaces:** bringing information, reasoning, and action into a clear workspace.
- **Systems software:** exploring how computers organize work, from operating systems to small programs built under tight constraints.
- **Graphics and simulation:** making physical behavior visible and testing ideas through interactive models.

I work with Python, TypeScript, JavaScript, and React. I'm interested in software that gives people more direct control over their tools, and in how much a small, carefully designed program can do.

### Public work

I'm building a collection of focused projects with runnable examples, clear documentation, and explanations of the decisions behind the code.
